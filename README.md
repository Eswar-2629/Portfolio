# Eswar Devisetty Portfolio

## How I Built It

I designed and developed this portfolio as a fast, accessible static website with semantic HTML, a reusable CSS design system, and lightweight JavaScript. The interface uses a consistent color and spacing system, responsive layouts, glass-style navigation, scroll-aware interactions, and a persistent dark/light theme.

Rather than adding a framework for a single-page portfolio, I chose native browser technologies to keep the site fast, easy to deploy, and easy to maintain. I also added reduced-motion support, keyboard-visible focus states, mobile navigation, scroll-progress feedback, and touch-friendly project cards to make the experience usable across devices and preferences.

The **Open resume** button opens `EswarDevisetty.pdf`, stored in this directory alongside `index.html`.
